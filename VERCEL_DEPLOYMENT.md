# Deployment note: Husie is self-hosted

This file is retained only so older project references do not break. The current Husie deployment direction is a self-hosted Docker/Compose stack, not Vercel. Use `README.md`, `MASTER_ARCHITECTURE.md`, `.env.example`, and `docker-compose.yml` for the current architecture.

The web app still uses Next.js, but Vercel is not required as a runtime platform.
